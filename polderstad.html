🧩 Custom assets
Replace the built-in houses, trees, buildings and traffic with your own models. Formats: .fbx and .obj (+ its .mtl, select both) straight from Maya, .glb / .gltf (Blender, Blockbench) and MagicaVoxel .vox. Start from the game's own models: 📁 Export model templates writes every built-in model as .obj + .mtl into a folder, in metres, front = +Z.
Front of the model faces +Z. In Blender, model it facing the Front view (numpad 1, i.e. −Y). If it comes in turned, use ↻. Add several files to one slot for random variants; drop files straight onto a slot. Auto-fit scales a model to its slot; turn it off to use real size (1 unit = 1 m). Use sets how many of them use your model, so you can mix yours with the built-in ones. Models are saved in this browser.
